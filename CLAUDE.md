# CLAUDE.md — Gamebin

GameBin — curate and share visual game lists, Steam import, custom profiles (gamebin.neorgon.com)

**Live:** gamebin.neorgon.com · **Port:** 8841

## Run

```bash
make serve
```

Then open http://localhost:8841. It must be served over HTTP — the app is ES modules, and `file://` blocks them.

## Data

- `localStorage['gamebin-state']`
- `localStorage['gamebin_prices']`
- `localStorage['gamebin_profile_']`
- `localStorage['gamebin_session']`
- Convex tables: `allowedVoters`, `categories`, `clerkAccountLinks`, `games`, `likes`, `lists`, `profiles`, `userSettings`, `users`, `votes` (see `convex/schema.ts`)

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/events.js`, `js/render.js` are already past it. Split when touching them, do not grow them further.
