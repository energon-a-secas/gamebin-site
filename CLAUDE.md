# CLAUDE.md: Gamebin

GameBin: curate and share visual game lists, Steam import, custom profiles (gamebin.neorgon.com)

**Live:** gamebin.neorgon.com · **Port:** 8841

## Run

```bash
make serve
```

Then open http://localhost:8841. It must be served over HTTP. The app is ES modules, and `file://` blocks them.

## Data

- `localStorage['gamebin-state']`
- `localStorage['gamebin_prices']`
- `localStorage['gamebin_profile_']`
- `localStorage['gamebin_session']`
- Convex tables: `allowedVoters`, `categories`, `clerkAccountLinks`, `games`, `likes`, `lists`, `profiles`, `userSettings`, `users`, `votes` (see `convex/schema.ts`)

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/events.js`, `js/render.js` are already past it. Split when touching them, do not grow them further.

## Gotchas

- Open and close the sign-in panel only through `js/auth-panel.js` (`setAuthPanelOpen`, `toggleAuthPanel`). The panel collapses with `max-height`, so its tabs and fields stay focusable unless it is `inert` while closed; toggling the `open` class directly puts them back in the tab order.
- The CSP in `index.html` is an allowlist: a host the code loads from must be in the matching directive. Covers load from `cdn.akamai.steamstatic.com`, the one host `js/steam.js` builds, and every cover was blocked until `img-src` listed it. `connect-src` does not list `amicable-chickadee-800.convex.site`, so the Steam price and tag lookups in `js/prices.js`, `js/steam.js` and `js/api.js` fail silently (as of 2026-11-14, waiting on the owner's call).

## Do not touch

- `js/neorgon-*.js` and `css/neorgon-*.css`: vendored kits, regenerated by `packages/neorgon-ui/sync-*.sh`.
- `convex/_generated/`: rebuilt by `npx convex dev`.
